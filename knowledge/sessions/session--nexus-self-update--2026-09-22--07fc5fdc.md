Rules:

## 4. Version identity

- `nexus.version`: one line, semver. Bumped on every release that changes a manifest-owned file. Companion `CHANGELOG.md` entry per bump.
- `.nexus/installed.json` in each host:

```json

  "installed_version": "1.0.0",
  "installed_at": "2026-09-22T12:00:00Z",
  "upstream_url": "https://github.com/AlexanderShaburov/Nexus.git",
  "upstream_ref": "main",
  "upstream_commit": "8ed7c6e3…",
  "baseline": {
    ".claude/hooks/_nexus_common.py": "sha256:…",
    "CLAUDE.md#protocol": "sha256:…",
    "…": "…"
  },
  "unknown_provenance": ["knowledge/specs/spec--system--foo.md"]
}
```

Region entries are keyed `path#id` and hashed on region content only. The commit is the ground truth for "changed since install"; the version is the human label.

## 5. Three-way comparison

For each manifest entry: `baseline` (installed.json), `local` (project now), `upstream` (target ref in the cache).

| baseline | local | upstream | Verdict | Action |
|---|---|---|---|---|
| = local | ≠ upstream | present | clean update | write upstream, update baseline |
| ≠ local | = baseline | present | customized, upstream unchanged | leave alone, list as customized |
| ≠ local | ≠ upstream, ≠ baseline | present | conflict | report, do not touch |
| = local | = upstream | present | identical | no-op |
| absent | absent | present | new upstream | add, set baseline |
| absent | present | present, = local | unknown provenance, matches | adopt local as baseline, no-op |
| absent | present | present, ≠ local | unknown provenance, differs | report; `baseline adopt` resolves |
| present | absent | present | deleted locally | report; restore only with `--restore` |
| present | present | absent | retired upstream | report "safe to remove"; never delete |
| region | markers missing | — | unmarked | report; fallback to runbook |
| any | any | absent and manifest says `create-if-absent` | — | no-op after first delivery |

Edge rules: compare bytes, no whitespace or line-ending normalization (CRLF hosts will show as customized; documented, not hidden). Executable bit is re-applied to `.claude/hooks/*.py` and `tools/*.py` after every write. A conflict on any hook file downgrades the whole run to exit 1 and still applies the non-conflicting files, unless `--all-or-nothing`.

## 6. Fetch mechanism

- Cache: `$XDG_CACHE_HOME/nexus/template` (default `~/.cache/nexus/template`), override `NEXUS_UPSTREAM_CACHE`. One cache serves every project on the machine.
- First use: `git clone --depth 1 --branch <ref> <url> <cache>`; later: `git fetch --depth 1 origin <ref>` then read with `git show <ref>:<path>`; nothing is checked out into the project.
- `--upstream <path>` accepts a local working copy (no network; used for testing and for the operator's own machine).
- Ref policy: `main` today. When tags exist, `--ref` accepts `vX.Y.Z` and `check` prefers the highest tag. Recorded commit makes either reproducible.
- All git calls have a subprocess timeout; any failure is reported by the CLI and swallowed by the hook.

## 7. SessionStart notifier

New non-enforcing hook `.claude/hooks/nexus-update-notifier.py`, registered as a second `SessionStart` entry after `nexus-bootstrap.py`. Spec mirror: a short section in the session-bootstrap spec, marked advisory.

- Throttle: `.nexus/update-check.json` `{checked_at, upstream_version, upstream_commit, outcome}`; skip when `checked_at` is under 24 h old.
- Budget: 6 s total, `git fetch` with a 4 s timeout; over budget → silent and `outcome: timeout`.
- Silent when: `.nexus/installed.json` absent; `git` missing; offline; `NEXUS_UPDATE_CHECK=0`; running inside the template (manifest present, installed.json absent).
- Output on success with a newer upstream, one line of `additionalContext`:
  `Nexus 1.4.0 is available (installed 1.2.0). Run: python3 tools/nexus-update.py plan`
- Never writes anything except its own throttle file. Never blocks.
